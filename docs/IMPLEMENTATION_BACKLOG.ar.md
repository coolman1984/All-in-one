## شروط عامة لكل ميزة

- لا يُعلن الحفظ قبل تثبيت البيانات، ولا النجاح عند اكتمال جزء فقط.
- إلغاء واضح، وأخطاء مفهومة، وحفظ الأصل، وتراجع مناسب.
- اختبار عربي ولوحة مفاتيح؛ واختبار طباعة عندما تمس الميزة المستندات.
- حالات الحد: ملف تالف، مصدر تغير، قرص ممتلئ، صلاحية مرفوضة، إغلاق قسري.
- إثبات على ويندوز الحقيقي للوظائف المرتبطة بأوفيس والحافظة والتصوير.
- تحديث [سجل القرارات](DECISIONS.ar.md) عند ظهور دليل جديد، وتحديث المرجعين المقروء والمرئي معًا.
