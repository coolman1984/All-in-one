# مساحة عمل واحدة لكل شغلك 🧩

مشروع برنامج مكتبي خفيف يجمع الجداول والمستندات والعروض وملفات القراءة والطباعة والصور ومارك داون والملاحظات، مع حافظة نسخ وتصوير شاشة ومساعد ذكي يعدّل داخل الأدوات نفسها.

📌 الحالة الحالية: توثيق الرؤية والطلبات والأبحاث وخطة التنفيذ. لا يوجد تطبيق مكتمل أو نتائج أداء مُقاسة بعد.

## الرؤية 🎯

- أدوات يومية مركّزة وتابات متعددة؛ مع واجهة واضحة وتكامل المحتوى.
- دفاتر وأقسام وصفحات، وصندوق وارد ينشئ صفحة لكل عملية نسخ مسموحة عند تفعيل الالتقاط.
- تصوير شاشة وأسهم ومربعات وكتابة على الصور، مع حفظ الأصل وطبقات شرح قابلة للتعديل.
- محررات أساسية للجداول والمستندات والعروض والصور ومارك داون وملفات القراءة والطباعة.
- مساعد جانبي يقرأ النطاق المختار ويستخدم أوامر البرنامج للتعديل والتراجع.
- دعم مخطط لكلود كود وكودكس وكلين عبر وصلات رسمية؛ قابلية التوسعة بحسب قدرات كل مساعد.
- تشغيل محلي للأساسيات، وحفظ واسترجاع، وتحميل محركات عند الحاجة، وعرض تدريجي للملفات الكبيرة.

## أول مسار نثبت به الفكرة 🛠️

نسخ محتوى، ثم صفحة في الوارد، ثم لقطة مشروحة، ثم تقرير، ثم تعديل من مساعد، ثم تراجع واسترجاع الجلسة بعد الإغلاق.

اختيار التكنولوجيا والأداء النهائي يُحسم بالقياس على ويندوز وملفات واقعية مسموحة. دعم صيغة ملف لا يعني تطابقًا كاملًا مع جميع خصائص برامجها الأصلية.

## قراءة النسخة المرئية 🖥️

نزّل الملف المرئي وافتحه محليًا في المتصفح. جيتهاب يعرض مصدره ولا يشغّله كصفحة داخل شاشة عرض الملفات. جميع محتوياته وتصميمه وبحثه داخل الملف؛ روابط المصادر وحدها تحتاج اتصالًا. لم يُنشر موقع أو خدمة مستضافة ضمن هذا التحديث.
